# psiphon-egress

Psiphon как второй выход для ноды xray / Remnawave. Он нужен для сайтов, которые
не пускают адреса дата-центров.

Туннель работает в контейнере. Его SOCKS5 публикуется на адресе, который доступен
только внутри хоста, и xray ходит в него через outbound из четырёх строк. Жизненным
циклом управляет systemd. Watchdog меняет выход, когда тот перестаёт быть *пригодным*.
Это другой вопрос, чем «жив ли туннель».

> Полная документация на английском: [README.md](README.md). Происхождение кода:
> [CREDITS.md](CREDITS.md).

## Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mtvworks/psiphon-egress/main/psiphon_install.sh) \
  --no-http --bind-loopback --region 'DE,NL,FR,AT,CH,SE'
```

Нужны root, docker, curl, `ss` (iproute2) и `flock` (util-linux).

- `--bind-loopback` публикует SOCKS на `127.0.0.1`. Подходит, если xray работает
  в сети хоста (`NetworkMode=host`). Иначе уберите флаг: тогда используется
  адрес шлюза docker0.
- `--no-http` не публикует HTTP-прокси. Он здесь не нужен, а порт 8080 на нодах
  часто занят, например CrowdSec.
- `--region 'DE,NL,…'` задаёт пул стран: каждая ротация переходит к следующей.
  Без флага Psiphon выбирает самый быстрый выход в любой точке мира.

Все значения проверяются до того, как что-либо записывается. Коды стран можно
писать в любом регистре, через запятую или пробел. Неверный ввод останавливает
установку.

**Переустановка** сохраняет прежние настройки:
- порты;
- регион и пул, включая текущий шаг ротации;
- списки deny/accept и настройки watchdog;
- образ, уведомления и метрики.

Явный флаг всегда важнее сохранённого значения. `--region ''` возвращает режим auto.

## После установки — маршрутизация

```bash
vps-psiphon routing
```

Команда печатает правила для панели. Без них outbound ничего не проводит. Обе
UDP-строки обязательны: этот SOCKS работает только по TCP.

## Проверка, что это не открытый прокси

```bash
vps-psiphon verify
```

Команда проверяет всех слушателей на портах SOCKS и HTTP. Она предупреждает и
о wildcard-адресе, и о публичном адресе. Окончательная проверка — с другой машины,
и эта команда **должна завершиться ошибкой**:

```bash
curl --max-time 20 --socks5-hostname <хост>:1080 https://api.ipify.org
```

Не используйте для этого `nc -z`. Некоторые провайдеры отвечают на TCP-рукопожатие
по любому порту, и `nc` покажет «open» даже для закрытого порта.

## Управление

```
vps-psiphon status                  выход, страна, капча, скорость
vps-psiphon verify                  проверка доступности извне
vps-psiphon routing                 правила для панели
vps-psiphon rotate                  новый туннель, следующая страна пула
vps-psiphon region DE | auto        закрепить страну
vps-psiphon pool 'DE NL FR'         пул ротации
vps-psiphon accept 'DE NL' | any    какие вердикты Google допустимы
vps-psiphon update-image [--check]  перейти на свежий digest образа
vps-psiphon notify-test             тестовое сообщение в Telegram
vps-psiphon speed                   скорость через туннель
vps-psiphon logs / watchdog         лог контейнера / журнал watchdog
vps-psiphon uninstall               удалить всё, включая саму команду
```

`rotate`, `region`, `pool`, `accept` и `update-image` используют одну блокировку
с watchdog. Поэтому ручная команда не попадёт в середину проверки.

## Обновление образа

Образ закреплён по digest, чтобы код на ноде не менялся незаметно. Но из-за этого
он и не получает исправлений сам. `vps-psiphon update-image --check` показывает,
вышла ли новая версия. Без `--check` команда переключается на новую версию и
перезапускает туннель, при этом активные соединения обрываются.

## Уведомления и метрики

По умолчанию выключены.

- **Telegram**: `--tg-token <токен бота> --tg-chat <id чата>`. Сообщения приходят
  в трёх случаях:
  - при каждой ротации, с причиной и новым выходом;
  - при первом появлении выхода в запрещённой стране;
  - если после ротации туннель не поднялся.

  Сообщения отправляются напрямую, не через туннель. Токен хранится в
  `/etc/default/vps-psiphon` с правами 0600 и не попадает в командную строку.
- **Prometheus**: если есть каталог `/var/lib/node_exporter/textfile_collector`
  (или указан `--metrics-dir`), watchdog после каждой проверки пишет туда
  `vps-psiphon.prom`.

Лог watchdog ротируется раз в неделю через logrotate.

## Предупреждения

**Не ставьте это на сервер внутри страны, из которой обходите блокировки.** Трафик
клиента Psiphon распознаётся DPI. Его можно заблокировать, а сервер по нему можно
опознать. Место для него — зарубежная нода, до которой вы уже добираетесь другим
транспортом.

**Запуск образа вручную — это открытый прокси.** Внутри контейнера psiphon
слушает `0.0.0.0`, поэтому `docker run -p 1080:1080` открывает SOCKS5 и HTTP-прокси
всему интернету без авторизации.
